Initial commit - Cyberpunk ASCII Renderer v4.0

Features:
- Convert images/videos/GIF to ASCII art
- True Color RGB support
- Multiple character sets
- Real-time keyboard controls
- Drag & drop support
- Export to TXT/HTML

Controls:
- Space: Pause/Resume
- C: Change color mode
- M: Change character set
- R: Reverse playback
- +/-: Adjust contrast
- ↑/↓: Adjust resolution
- Q: Quit

Requirements:
- Python 3.8+
- opencv-python
- Pillow
- numpy

Run setup.bat to install dependencies and start.
